# Orchestrate on Cursor

The Cursor profile retains the existing source-only plain-file helper at `pstack/skills/poteto-mode/scripts/orch/orch.ts`. It may use Cursor-provided cloud delegation, transcript inspection, recurring loops, and Graphite when those capabilities are present.

Keep those operations in this runtime profile. The shared Orchestrate playbook owns briefs, exact-revision evidence, queue discipline, and one integration authority. It does not name Cursor tools or paths.

The Codex SQLite journal is a separate runtime adapter. It does not replace or migrate existing Cursor plain-file stores in this release.
